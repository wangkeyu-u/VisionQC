# VisionQC 零基础使用指南

这份指南写给从未使用过代码、Docker 或 AI 模型的人。你不需要准备真实工厂数据，也不需要理解 PatchCore、API、MES 或 QMS。

## 你会体验到什么

VisionQC 会用一张内置的工业产品演示图片，带你完成完整质量流程：

1. 上传图片；
2. 查看系统指出的可疑区域；
3. 由人确认合格、返工、报废或继续调查；
4. 跟踪质量事件，直到问题关闭。

> 演示图片由 Blender 合成生成，MES 和 QMS 也是模拟系统；它们不会连接或修改任何真实工厂系统。

如果你要体验 Dürr 汽车涂装概念路线，请从左侧“开始检测”进入向导。页面会让你选择“示例图 / 文件夹 / USB 相机”，先做预检，再开始检测；你会看到车身数字质量档案（body/workpiece、涂装车间、喷房/工位、产线、车型、颜色、配方、班次）以及人工复核后的模拟质量闭环。

> **面向 Dürr 业务场景设计的独立作品集概念方案 / Independent portfolio concept; not commissioned or endorsed by Dürr.** `dxq_mock`、MES 和 QMS 都是明确的模拟适配器，不是真实 DXQ 接口。

默认选择“本地处理，不上传原图”。若选择文件夹或 USB 相机，只有你明确打开“同意把数据发送给项目/服务”并填写用途后，才允许上传；页面会显示同意状态、用途、保留期限与删除方式。

## 第一次启动（macOS）

### 1. 安装 Docker Desktop

打开 [Docker Desktop 下载页面](https://www.docker.com/products/docker-desktop/)，安装后启动应用。等到菜单栏里的鲸鱼图标显示 Docker 正常运行。

### 2. 双击启动

在 VisionQC 项目文件夹中双击 `start-demo.command`。

- 第一次运行需要下载和构建组件，通常需要几分钟。
- 启动完成后，浏览器会自动打开 `http://localhost:3000/`。
- 如果 macOS 阻止运行，请右键文件，选择“打开”，再确认一次。

### 3. 完成三分钟演示

进入首页后：

1. 点击首页“开始检测”或“使用演示图片开始”；
2. 确认页面已经自动载入 Blender 生成的晶体管演示图片和批次信息；
3. 点击“开始检测”；
4. 在结果页先查看“原图”，再切换“叠加”；
5. 点击“由我确认这张图片”；
6. 选择一个人工结论并填写你实际观察到的内容；
7. 如果创建了质量事件，继续打开事件页查看后续动作。

任何时候看不懂，都可以点击右上角“使用帮助”。顶部“系统连接正常”按钮会告诉你当前是否可以继续，以及连接失败时应该检查什么。

## 停止演示

回到项目文件夹，双击 `stop-demo.command`。它只停止 VisionQC 演示服务，不会删除已经生成的演示记录。

## 常见问题

### 页面打不开

先确认 Docker Desktop 正在运行，再双击一次 `start-demo.command`。如果仍打不开，等待两分钟后访问 [http://localhost:3000](http://localhost:3000)。

### 顶部显示“连接需要检查”

点击该状态查看具体项目：

- “业务服务”“图片存储”或“异常检测服务”异常：重新启动演示；
- 只有“现场采集设备”异常：仍然可以用网页手动上传演示图片；
- 重新检查后仍失败：把连接面板中的失败项和启动窗口最后 20 行发给维护者。

### 我没有真实数据

不影响体验。首页的“使用演示图片开始”会自动载入 Blender 合成样本。它包含一个弯折引脚以及对应的像素掩码，并且可以通过项目脚本重新生成。真实客户数据只有在 Pilot 阶段完成授权、来源登记和隐私检查后才需要导入。Blender 汽车涂装图片同样是 `DEMO_SYNTHETIC`，不能证明喷涂现场准确率。

### Blender 图片是真实检测结果吗

不是。它只帮助你理解系统流程、测试上传和展示人工复核。它不能用来证明模型在真实工厂中的准确率，也不会让候选模型通过生产上线门槛。

### 热力图是不是在告诉我哪里坏了

不是。热力图只表示模型对哪些区域反应更强。它不能单独确认缺陷类型、故障原因或最终处置，人工复核仍然是必需步骤。

## 常见术语

| 页面术语 | 普通语言解释 |
| --- | --- |
| Gateway | 现场接入程序，把相机或文件夹中的图片送到 VisionQC |
| Deployment Pack | 当前工厂的产品、工位、阈值和连接配置 |
| MES | 生产管理系统；演示中是模拟接口 |
| QMS | 质量管理系统；演示中是模拟接口 |
| ModelOps | 模型版本、测试证据和上线门槛管理 |
| 异常分数 | 图片与正常样本的差异程度，不是缺陷概率 |
| 热力图 | 模型关注区域，不是缺陷确认 |

## 向导里的三种输入

| 选择 | 会发生什么 | 当前边界 |
| --- | --- | --- |
| 示例图 | 使用项目内演示图片，适合三分钟体验 | 合成证据，只证明流程 |
| 文件夹 | Gateway 监控目录，经过稳定性、清晰度、曝光和命名预检 | 默认本地队列；同意后才可上传 |
| USB 相机 | 通过可选 OpenCV 采集一帧进入同一队列 | 没有驱动/硬件会给出人话错误；可用 mock 测试 |

图片模糊、太暗、过曝、低对比度、无目标或视角不可靠时，系统会进入复核/Hold，不会自动放行。
