# VisionQC Site Acceptance Test（Pilot）

本验收表用于现场 Pilot 的 Go/No-Go，不替代客户质量体系批准。

## 数据与模型

- [ ] 提供官方 MVTec 或经批准的现场数据来源、许可证、获取日期和 SHA-256 receipt。
- [ ] `data validate`、manifest verify 和 split 泄漏检查通过。
- [ ] Protocol A 使用正常训练集，Protocol B 的阈值只来自 calibration，holdout 未被调参。
- [ ] 模型包、特征库、阈值、证据包和 Deployment Pack 摘要一致；篡改负测通过。
- [ ] 现场正常/缺陷抽检样本、标签规则、复核人和时间窗口已签字。

## 现场成像与抽检

- [ ] 相机位置、视场、焦距、曝光、增益、白平衡、灯光和背景已锁定并拍照留档。
- [ ] 每个工位完成正常基线和代表性缺陷抽检；新批次按约定比例人工复核。
- [ ] 记录图片质量拒绝、异常分数分布、Review/Hold 率、漏放和误报。
- [ ] 相机、灯光、夹具、产品 revision 或工位变更会触发重新校准/重新评测。

## 业务闭环与安全

- [ ] 自动放行只发生在低于 review 阈值；异常路由不会直接确认语义缺陷或根因。
- [ ] 复核、暂扣、返工、报废、调查及 MES/QMS 写操作均由具名角色完成并带 reason/correlation_id。
- [ ] 多租户访问、跨客户模型/证据引用和跨产品激活均拒绝。
- [ ] 未通过门禁的候选显示 `INSUFFICIENT_EVIDENCE`/`REJECTED`，激活按钮不可用。
- [ ] 复核负担、延迟、队列、Connector 重试和事件闭环回归无异常。

## 漂移、回滚和决定

- [ ] 定义输入质量、分数、业务误放/误杀、复核率和热 P95 监控阈值。
- [ ] 漂移或门禁回归时，默认进入 Review/Hold，停止自动激活并打开调查。
- [ ] 已批准上一版本可在包摘要校验、绑定当前 Pack 和具名理由后回滚；历史检测不可重写。
- [ ] Go 仅在全部强制门槛、现场抽检、权限分离、完整性和回滚演练通过时成立。
- [ ] No-Go 或证据不足时，系统保持 Demo/Stub 或人工复核路径；不得声称生产效果。
